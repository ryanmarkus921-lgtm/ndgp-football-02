# NDGP Football

A completely new NDGP Football web app built from scratch.

## Stack
- HTML / CSS / JavaScript
- Supabase
- Vercel
- GitHub

## Files
- `index.html` — public app
- `styles.css` — public design
- `app.js` — public app logic
- `admin.html` — private management screen
- `admin.css` — admin design
- `admin.js` — admin logic
- `LOGO_W__FB.png` — official logo

## Deploy
Upload the contents of this folder to the new GitHub repository and connect that repository to Vercel.

The public app is the repository root. The admin page is `/admin.html`.

## Important
The Supabase publishable key is intended for browser use. Never put a Supabase service-role/secret key in this project.

Admin authentication uses Supabase Auth. The admin email is the email you created in Supabase, and the admin password/code is the one you set there.
